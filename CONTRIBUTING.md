# Contributing

Thanks for contributing to Laravel Users.

## Workflow

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Keep changes small and clearly scoped.
4. Run the relevant tests before submitting.
5. Open a pull request with a clear description of what changed and why.

## Bug reports

When reporting a bug, include the Laravel version, PHP version, steps to reproduce, expected behavior, and actual behavior.

## Pull requests

Please avoid unrelated formatting changes and keep each pull request focused on a single improvement or fix.
